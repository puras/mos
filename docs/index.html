七大核心能力

全部是已落地的代码，不是名词。

🔌

统一 LLM 接入

OpenAI / Anthropic / Gemini 三协议一套接口，换模型不改业务；用量口径跨协议可比。

🧰

声明式工具系统

写个 struct 就是工具，schema 自动生成；tool_search 让千级工具面 token 亚线性。

🎓

Skills 技能

目录里的 SKILL.md 就是技能：清单进提示词、正文按需加载，渐进式披露不占常驻上下文。

📓

事件日志会话

append-only 日志是唯一事实来源，崩溃恢复只补事件不改写，重启即续跑。

🔁

可插拔循环驱动

LoopDriver 接口化：新增一种循环 = 一个 Run 实现，不污染共享设施。

✂️

上下文工程

截断落盘可回读、压缩不切断调用对、提示词静态分节——prompt cache 友好。

📡

全链路可观测

turn / tool / approval / compaction 全落日志；Describe() 装配快照，缺什么如实说。

安全纵深：四层防线

结构性让误用与逃逸难以发生。

① Policy 规则

工具黑白名单，未知工具一律拒绝

② Guard 守卫

串行单调裁决，钩子结构上无法绕过

③ 沙箱隔离

文件 jail + 进程沙箱，写前观察门

④ 人工审批

参数级 deny/ask 转人工，动作全留痕

fail-closed 是全库纪律：未知工具拒绝、缺能力即报错、审批未配置即拒绝——绝不静默降级。

Skills：给智能体装上可复用的本事

一个技能 = 一个目录 + 一个 SKILL.md。写文档就能扩展智能体，不用写代码。

渐进式披露

清单进提示词（常驻），正文由 skill 工具按需加载——技能再多不吃上下文

清单有预算

清单超预算先丢描述再丢条目，丢了多少如实告知，不静默截

用户手势 /name

宿主拿到输入时调 ExpandInvocation 展开；disable-model-invocation 的技能只能用户调

边界清晰

读技能不走 read 工具——与工作区读权限分开；不合法技能不装并出诊断

协议层独立：MoProto

LLM 协议归一、密钥管理、模型路由——独立仓库、独立版本、独立演进。MoS 只消费它的纯定义包（pkg/），不依赖网关实现层。
