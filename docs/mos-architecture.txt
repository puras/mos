图例
  实线   = 直接依赖/注入
  虚线   = 内嵌/旁路 (如 Driver 内嵌 react)
  虚+△   = UML 实现 (L8 实现 L6 的接口)

关键拓扑
  ① Assistant 是唯一公开入口
  ② Driver 实现间存在 "内嵌 react" 复用
    (planexecute / reflection 内部都用 react 做步骤执行器)
  ③ session.Session 是事件日志唯一事实源
    所有 Driver / 扩展点向其落事件
  ④ HookBus 可改写环节, GuardBus 单调守卫
    driver.Policy 经 GuardBus 注入, 普通钩子改不绕过
  ⑤ Skills 两段职责:
    skills.go      —— 清单懒加载注入系统提示词
    activate_skill —— 模型按需激活拿正文 + references/
  ⑥ L6 只声明接口, 实现分别落在 L7 (tool) 和 L8 (llm)
