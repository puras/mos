# 多 Agent 协作系统

基于 MoS 框架实现的智能任务协作系统，包含三个专业 Agent：拆解专家、执行专家、验收专家。

## 快速开始

```bash
# 编译
go build -o agents .

# 运行
./agents
```

## 使用方式

进入交互模式后，输入命令：

```
➜ 请输入命令: new 写一篇关于AI的文章
✅ 任务已创建: #1 - 写一篇关于AI的文章

➜ 请输入命令: run 1
🚀 开始处理任务 #1
   描述: 写一篇关于AI的文章

📋 [阶段1] 任务拆解 - 负责人: 拆解专家
   ✅ 拆解完成，共 4 个子任务:
   1. 📋 分析需求：理解文档主题和目标读者
   2. 📝 构建大纲：组织内容结构
   3. ✍️ 撰写初稿：按照大纲填充内容
   4. 🔍 审阅修订：检查语法和逻辑

⚡ [阶段2] 任务执行 - 负责人: 执行专家
   ⏳ 正在执行: 📋 分析需求：理解文档主题和目标读者
   ...（依次执行）
   🎉 所有子任务执行完毕！

🔍 [阶段3] 任务验收 - 负责人: 验收专家
   ✅ 验收通过：任务已完整执行，所有步骤均已完成

🎉 任务 #1 已完成！

➜ 请输入命令: list
📊 当前任务列表
============================================================

✅ 任务 #1 - 写一篇关于AI的文章
   状态: completed | 子任务: 4 个
   创建时间: 15:55:00
   验收结果: ✅ 验收通过：任务已完整执行，所有步骤均已完成
============================================================
```

## 可用命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `new <任务>` | 创建新任务 | `new 实现用户登录功能` |
| `run <ID>` | 执行任务 | `run 1` |
| `list` | 查看所有任务 | - |
| `clear` | 清空所有任务 | - |
| `help` | 显示帮助 | - |
| `quit` | 退出程序 | - |

## Agent 架构

```
┌─────────────────────────────────────────────────────────────┐
│                      用户提交任务                             │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│                    Pipeline 流水线                           │
│                                                             │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐  │
│  │  拆解专家     │ →  │  执行专家     │ →  │  验收专家     │  │
│  │  (Planner)   │    │  (Worker)    │    │ (Reviewer)  │  │
│  │              │    │              │    │              │  │
│  │ • 智能拆解   │    │ • 执行子任务 │    │ • 结果验收   │  │
│  │ • 生成计划   │    │ • 生成报告   │    │ • 判断通过   │  │
│  └──────────────┘    └──────────────┘    └──────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 支持的自动识别类型

| 关键词 | 识别类型 | 子任务 |
|--------|---------|--------|
| 文档、写 | 文档类 | 分析需求→构建大纲→撰写初稿→审阅修订 |
| 代码、实现、功能 | 代码类 | 需求分析→架构设计→编写代码→单元测试→安全检查 |
| 研究、调研 | 研究类 | 信息收集→数据分析→撰写报告 |
| 其他 | 通用类 | 理解目标→制定计划→执行步骤→验证标准 |

## 核心特性

1. **交互式命令行** - 友好的 CLI 界面
2. **任务自动拆解** - 根据任务类型智能生成子任务
3. **三阶段流水线** - 拆解 → 执行 → 验收
4. **状态管理** - 完整的任务状态流转
5. **任务列表** - 随时查看所有任务状态
