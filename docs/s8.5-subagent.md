## 一句话

**子代理 = 一个普通工具**。主 Agent 用 function calling 点名调用它，它在自己的会话里用**收窄过的工具面**干活，只回一段**固定结构**的结果。

## 五个决定（MoS 的取舍，2026-11-06 拍板）

1. **形态**：agents-as-tools + 声明式定义（frontmatter，对齐 `.claude/agents/` 风格）——PI 无此层，DSH 的子代理是运行期创建的会话、没有声明式角色目录 → **MoS 自创**。工具名 `subagent__<name>`（对齐 MCP 的 `mcp__<server>__<tool>` 命名空间惯例）。
2. **交付**：**同步**（父轮次等结果）——不抄 DSH 的「异步返回 id + 另行通知」，因为 MoS 没有运行期消息回注通道。
3. **白名单**：**取交集、deny 优先**——子代理实际工具面 = 声明白名单 ∩ 父可见工具集 ∩ 宿主 policy。**声明的白名单不能放大宿主策略**（DSH 同款：`toolFilter` + 父策略向下委派）。
4. **回执**：固定结构 `{status, summary, findings[]}`，`summary` 是**子代理自述**。按 NFR-5，子代理的结论**不进父的 `TaskState`**——父模型只能当线索，**要自己复核**。
5. **留痕**：**不加** `subagent/*` 事件（治理规则 2 事件预算制，那一档留给 M3b 的 AgentTeam）。父会话只留 `tool/call` / `tool/result`；子代理内部的调用记在**子会话**日志里——「中间工具调用留内部」因此自然成立。

## 目录长什么样（v1 定稿）

```
<subagent-dir>/
  reviewer/
    AGENT.md          # frontmatter + instructions 正文
```

```yaml
---
name: reviewer            # kebab-case（同 Skills 口径）
description: 只读代码审查，产出问题清单
model: fast               # 可选：模型覆盖（宿主目录里没有 → 装配期报错）
tools: [read, grep, ls]   # 白名单：与父可见集、宿主 policy 取交集
---
你是严格的代码审查者。只报告问题，不改文件。
```

清单（name + description）**进静态系统提示词**（装配期渲染一次 → 保 prompt cache），预算降级照抄 Skills 的「清单预算受限」。

## 几条硬纪律

| 纪律 | 落点 |
| --- | --- |
| **声明了却没装 = 假能力**：模型覆盖指向宿主目录里不存在的模型 → 装配期报错，不静默降级到父模型 | 装配层 |
| **子代理失败不是父轮次失败**：回执 `status: error` 是正常工具结果，父模型看得见、可自纠（同 §3.1「工具报错是结果」） | 工具执行 |
| **超时与取消**：子代理超时 = 工具级超时（同 MCP `callTimeout`）；父轮次取消 → 子代理跟着取消 | 工具执行 |
| **子代理的工具调用照常受管**：走同一个 `agent/execpath`（policy / guard / 审批）；审批沿用同一个宿主 `approval.Answerer` | 执行通道 |
| **框架不自己造 Agent**：`agent/subagent` 只定义 `Runner` 接口，执行体由装配层提供（避免根包与子包成环；治理规则 5） | 包结构 |
| **不拆没差别的子代理**：`instructions` / `tools` / `model` 三者与父全同 → 装配期给诊断（PRD FR-D3 的拆分判据） | 装配层 |
| **子代理不能再委派**：深度 0（v1 不做子代理套子代理）；DSH 的 `resolveChildDepth` 是现成参照，M3b 再放开 | 工具执行 |

## 拍板结果（2026-11-06，用户已决：六条全按建议）

| # | 事项 | 结论 |
| --- | --- | --- |
| 1 | 交付形态 | **同步**——父轮次等子代理跑完，结果作普通工具结果回填（MoS 没有异步结果回注通道） |
| 2 | 工具命名 | `subagent__<name>` |
| 3 | 白名单与父策略 | **取交集、deny 优先**——声明的白名单不能放大宿主策略 |
| 4 | 模型覆盖 | 允许声明 `model`；宿主目录里没有 → **装配期报错**（声明了却没装 = 假能力） |
| 5 | 能否再委派 | **禁止**（深度 0） |
| 6 | 与 `tool_search` 的关系 | 子代理工具面**不经** `tool_search`；子代理工具本身**不** deferred 化（数量多了再评估） |

理由与代价见 `docs/ARCHITECTURE.md` §3.18「拍板结果」表。

## 没做的

- **续跑（continuable）**：DSH 有 one-shot / continuable 两态 + `send_message` 续跑——PRD 没要求，续跑要子会话冷启动 + 事件溯源 → 留给 M3b。
- **AgentTeam（FR-D6）**：Team Lead / Shared Task List / Mailbox / 落盘重建 → M3b（连带申请 `subagent/*` 事件预算）。
- **并行 DAG（FR-D4/D5）**、**合约 + Elo（FR-D7/D10）** → M3b。
- **子代理套子代理**：v1 深度 0（禁止）。
